# EliteHomes — Real Estate Website

A responsive real estate website concept for presenting property listings, property types, popular locations, real estate services, and helpful resources.

## Highlights
- Real estate landing page and responsive navigation
- Featured property cards and property categories
- Popular locations section
- Real estate services and resources
- Testimonials and FAQ sections
- Contact form interface

## Built With
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap JavaScript
- Font Awesome

## Run Locally
Clone the repository, then open `EliteHomes/index.html` in a browser.

## Project Structure
- `EliteHomes/index.html` — page markup
- `EliteHomes/styles/` — Bootstrap, custom, and responsive styles
- `EliteHomes/js/` — Bootstrap and icon scripts
- `EliteHomes/Images/` — property and profile images
- `EliteHomes/assets/fonts/` — local font files
- `EliteHomes/webfonts/` — icon fonts

> The contact form is a frontend UI; no form-submission backend is included.
