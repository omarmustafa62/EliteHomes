# EliteHomes – Real Estate Website

A real estate website concept for exploring featured properties, property categories, locations, and real-estate services.

## Features
- Real estate landing page
- Featured property listings
- Property categories and popular locations
- Services and resource sections
- Responsive navigation and layout

## Built With
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Run Locally
1. Clone this repository.
2. Open `EliteHomes/index.html` in your browser.

## Project Structure
The website source is inside `EliteHomes/`. Images, stylesheets, scripts, and fonts are stored in separate asset directories.
